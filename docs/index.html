File formats

Cables: one line per span. A shapefile goes in as a .zip holding the .shp and .dbf (add the .prj if you have it). A .kml or .kmz needs attributes inside it; one drawn by hand in Google Earth has only names. Any column names work: you match them after loading.

Needed: cable ID and the structure at each end. Compared when present: fiber count, length in feet, placement. With no length column, length can be measured from the line.

Splices (.csv): columns closure_id, structure, backbone_cable, bb_start, bb_end, branch_cable, br_start, br_end.

Records (.json): what the extract command writes. Sample files are in the repository's examples folder.

Files are read in your browser and are not stored. Notes are sent to Claude only when you press Extract. Do not load records you are not allowed to share.
